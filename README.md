# SIGNAL / BUILD — Santhosh Reddy Mandli

A custom, responsive portfolio built with plain HTML, CSS, and JavaScript. The visual concept is a "developer constellation": projects and skills connect around a central build node.

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser, or use Live Server.

No npm install, framework, or build step is required.

## Before publishing
- Confirm your LinkedIn and LeetCode URLs and email.
- Skill indicators are visual design elements, not objective test scores; adjust them to match your confidence.
- Add real GitHub repository and live-demo links after publishing your projects.
- The Django/FastAPI/REST API/Git section is labelled as a future learning path, not as existing expertise.
- Check every project description against what you can explain in an interview.

## Deploy
This static website can be published through GitHub Pages, Netlify, or Vercel.
